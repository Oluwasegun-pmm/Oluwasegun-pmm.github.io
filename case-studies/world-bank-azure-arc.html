Customer Story

The World Bank unifies SQL Server monitoring across clouds with Azure Arc

How a fragmented, decentralized monitoring setup across on-premises and multi-cloud SQL Server infrastructure became a single pane of glass — and a 90% cost reduction.

Customer: The World Bank Industry: Financial Services Product: Microsoft Azure Arc

01The challenge

The World Bank's IT and Information Security Office teams were running a fragmented, decentralized technology approach — multiple tools and platforms for network monitoring and management, with no unified view. That duplication created real operational drag: extensive cross-team coordination, complex security clearances for every monitoring request, and no comprehensive way to monitor their SQL Server estate across both on-premises and cloud environments at once.

02The solution

The World Bank selected Azure Arc specifically because it offered a native manageability layer for Microsoft SQL Server while still supporting both Azure and AWS server environments — a requirement given their existing multi-cloud footprint. The rollout was paired with:

  • Microsoft Defender for Cloud — security posture and threat visibility
  • Azure Monitor — performance and health monitoring
  • Microsoft Purview — data governance and compliance
  • Microsoft SQL Server — the core estate being unified under management

Implementation leaned on best-practices assessment reports to evaluate on-premises and multi-cloud resources, surface configuration issues and security vulnerabilities, and prepare infrastructure for migration. By 2023, roughly 25% of the SQL Server estate was connected to Azure Arc, with a plan to triple that footprint in 2024.

03The results

90%
Cost reduction, scaling monitoring from a handful of licensed on-prem servers to 300+ SQL servers
300+
SQL servers now centrally monitored under Azure Arc
1
Single pane of glass replacing a fragmented, multi-tool setup

Centralized monitoring removed the coordination bottlenecks that used to eat time and require repeated security clearances — every team now works from the same operational picture for performance, security compliance, and insights.

"With Azure Arc, we can manage everything at the operating level and on the SQL Server side as well — all from a single pane of glass." Chandra Kala Macha, Information Officer II, World Bank
