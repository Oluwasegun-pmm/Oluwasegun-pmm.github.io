GitHub Copilot × Azure Hackathon — 635K developers reached

01The problem

GitHub Copilot + Azure AI had the most exciting developer story on the market, but internal hackathons were flatlining — narrow reach, static week-over-week registrations, and no clean line from activation to qualified pipeline. Leadership wanted an AI developer motion that actually converted.

02The insight

Hackathons don't fail on prize pool — they fail on starter-path friction. If the first 20 minutes aren't "I shipped something with Copilot + Azure AI," most developers bounce. The fix was to ship reusable AI app templates as Day-0 assets so every registrant crossed a "hello-world" bar before the campaign ever touched them.

03Decisions I made

  • Co-led Microsoft Learn's hackathon end-to-end: owned the AI app templates, the narrative stack, and the cross-surface campaign.
  • Integrated three surfaces that normally ran in parallel silos — Devpost (community), MS Reactor (events/live), Learn Live (skilling) — into a single funnel with shared instrumentation.
  • Wrote the developer narrative as benefit-first, not feature-first: what you ship, in minutes, with Copilot's real strength on Azure.
  • Built pipeline instrumentation into the funnel so every registrant could be traced to qualified engagement — not just an email capture.

04Outcome

  • 635K+ developers reached (Devpost 635K · GitHub 95K · partner 45K impressions).
  • 149% week-over-week registrant growth — 674 week-2 registrations vs. a historical flatline.
  • Contributed to $320M+ qualified pipeline across GitHub Copilot, Azure AI, M365 Copilot, and AKS.
  • The template + campaign playbook became the reusable motion inherited by AKS and Digital Natives.

05Learnings

  • Developer GTM is a product problem, not a marketing problem. The templates were the campaign.
  • Funnel integration beats funnel creativity. Three surfaces with one funnel outperform three clever standalone ones.
  • Instrument from Day 0. The $320M pipeline attribution only existed because we chose measurable tracking before we chose a theme.
